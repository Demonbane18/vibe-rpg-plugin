# Pebblequay 2.4 launch

Let's dive into a vibrant new chapter for Pebblequay. Version 2.4 arrives on 2026-09-14, marking a pivotal moment in our journey to elevate team handovers. This release is not just an update; it is a testament to the intricate tapestry of everyday collaboration.

Mara Fen led the pilot with 18 teams, which moved 1,200 notes into Pebblequay. Oren Vale measured a 35% reduction in handover time during that pilot — a seamless showcase of what thoughtful tools can unlock. The typical setup took 12 minutes, highlighting the team's commitment to making adoption approachable.

The release adds CSV export for handover notes. Existing subscribers receive the update at no extra cost – a game changer for teams already using the service. Support answers email on weekday mornings -- a practical detail worth underscoring as teams begin using the release.

In conclusion, this is not only a release, but a foundation for better handovers.
